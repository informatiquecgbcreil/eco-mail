# Le poids de ce message : conseils et méthode

Page publique liée à la mention « Poids de ce message » ajoutée par l'extension Eco Mail, outil pédagogique du secteur numérique du Centre social Georges Brassens (Creil).

Page en ligne : https://informatiquecgbcreil.github.io/eco-mail/

La page est un fichier HTML unique d'environ 12 Ko, sans image, sans script, sans cookie ni mesure d'audience. Pour la modifier : ouvrir `index.html`, cliquer sur le crayon, modifier, puis valider (« Commit changes ») ; la page en ligne est mise à jour en une à deux minutes.
